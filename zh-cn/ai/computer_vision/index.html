Pretext tasks from image transformations

Pretext task：不是最终任务，而是为了训练 encoder 设计的代理任务

  • rotation：让模型去学判断这个图片被旋转了多少度。4-way classification
  • predict relative patch locations：8-class classification task
  • Inpainting:

    • 拿一张完整图片 x，人为遮住一块，得到 corrupted image。

    • 输入 corrupted image，让模型预测被遮住区域的 pixels。

    • 原图中被遮住的那一块就是 target，所以不需要人工 label。

    • 有两个 model:

      • F: inpainting model / generator，用来补全缺失区域。
      • D: discriminator，输出“这张图是真图”的概率。

    • 训练方式是交替训练：

      1. 先用 F 生成补全后的 fake image。
      2. 训练 D： 用 BCE loss 分辨 real image 和 fake image。 real image label = 1 fake image label = 0
      3. 再训练 F： loss = reconstruction loss + adversarial loss。 reconstruction loss 让补出来的 pixels 接近真实 pixels。 adversarial loss 让补出来的图骗过 D，让 D(fake) 接近 1。

    • Reconstruction loss: 只在 masked region 上算预测 pixels 和真实 pixels 的差距。 目标是内容要对。

    • Adversarial loss: 本质是 BCE / GAN loss。 对 D 来说：学会分辨 real/fake。 对 F 来说：学会生成让 D 以为是真的 fake image。 目标是视觉上更真实、更不模糊。

Contrastive representation learning

Gen

Definition

Discriminative Model

给定一个输入 x，它属于哪个 label y。数学上就是学：p(y | x)。
比如给一张cat image, 输出cat/dog label
No way to handle unreasonable inputs

Generative Model

学习：这张图片本身有多像真实世界里会出现的图片？即p(x) = 这张图片的合理程度
Model can “reject” unreasonable inputs by giving them small probability mass.

Conditional Generative Model

学习p(x | y)，比如p(image | “cat”)， 即给定条件是 cat，哪些图片像猫？

Gen Models

Explicit Density

模型显式地建模 p(x)，所以可以对一个输入 x 计算它的概率/likelihood。

Autoregressive models
  • 真的可以计算出prob,而不只是估计
  • 把 x 拆成 sequence，然后每一步根据前面的内容预测下一个元素。因此它能用chain rule显式计算 p(x)。
  • LLM是Autoregressive models
  • 也可以用来生成图片。
    • pixel cnn: 给定前面的 pixels，现在这个 pixel 的值应该是多少？因为每个像素点是3 channel的0-255取值，cnn生成一个256 维 softmax，代表下一个pixel的值的概率分布
    • p(x) = p(x1) * p(x2 | x1) * p(x3 | x1, x2) * …，可以学习整张图片的概率
Approximate density

想建模 p(x)，但只能近似计算。
用一个隐藏空间 z 表示数据背后的因素，再从 z 生成 x

(Non-Variational) Autoencoders
  • 图片经过encoder(mlp/cnn),输出features（object identity， appearance， scene type），目的是学这个encoder
  • x -> Encoder -> z -> Decoder -> x_hat. loss = ||x_hat - x||^2
  • backprop 会同时更新 encoder 和 decoder 的参数。encoder 像模型前半部分，decoder 像模型后半部分。
  • 中间的 z 是 learned representation / compressed feature。

问题: 普通Autoencoder的逻辑是，如果我们可以生成一个z,然后用decoder就可以生成一个图片。但关键在于，很难学会生成一个有意义的z

VAE

Variational Autoencoders (VAE) define an intractable density that we cannot explicitly compute or optimize

But we will be able to directly optimize a lower bound on the density

  • training data: x
  • intuition: maximize pθ(x)，也就是在当前模型 pθ 下面，这些 training images 被生成出来的概率 / density

  • decoder:

    • input z, output μ_{x|z}
    • learn pθ(x | z) = N(μ_{x|z}, σ²)
    • if image: 28*28 pixels, then output 784 means
    • 假设所有 pixel 用同一个固定 variance σ²

  • encoder:

    • learn qφ(z | x) = N(μ_{z|x}, Σ_{z|x}), which approximates p(z|x)
    • input x, output μ_{z|x}, Σ_{z|x}
    • Σ = diagonal vector, 只考虑每个pixel有自己的 variance，但不建模不同pixel之间的 correlation。

  • user bayes to calculate p(x)=p(x|z)*p(z)/p(z|x)

  • want to maximize p(x) <=> loss function=-log(p(x))

  • training

    • 前两项叫做ELBO，第三项叫做gap. 因为KL>=0, 所以ELBO是loss的一个lower bound. 训练时，只优化前两项
    • 第一项：reconstruction term。给定一个x, 从encoder学到的分布里面sample很多z,对每个z计算log(p(x|z))，也就是把z丢给decoder, 看decoder 有多大概率重建出原来的 x,然后对这些结果取平均。这一项的目的是锻炼model的reconstruction能力，让encoder和decoder变得更好
    • 第二项：- D_KL(qφ(z|x) || p(z))。生成的时候，直接从预先规定的 z 分布，通常是 N(0, I)中，sample一些z. 这里的p(z)就是prior distribution。在训练的时候就假设p(z)服从标准高斯。这一项的目的是每个样本的 qφ(z|x) 被 regularize 到不要离 p(z) 太远.这样训练完后，我们才能直接从 p(z) sample z，再用 decoder 生成新图片。 KL代表两个distribution有多不像
    • 第三项：+ D_KL(qφ(z|x) || pθ(z|x))。注意pθ(z|x)是true posterior。代表：如果我已经看到了图片 x，那在当前decoder里，到底哪些 z 最可能生成这张 x？我们用encoder qφ(z|x)去approximate true posterior. 因为pθ(z|x) 算不出来，所以第三项算不出来

  • summary： Jointly train encoder q and decoder p to maximize the variational lower bound on the data likelihood
