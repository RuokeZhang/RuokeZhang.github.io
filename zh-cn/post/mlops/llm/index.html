推理模型的 prompt

  1. 保持简洁
  2. 不用提供太多示例，示例会降低推理效果

常见prompt

  1. markdown 格式（任务指令提示和系统提示）
  2. 角色扮演（任务指令提示和系统提示）
  3. 奖励机制/情绪激励(任务指令提示)
  4. 具体的示例
  5. 隐式思维链：让它输出思考过程：“请一步一步地思考”(任务指令提示和系统提示)
  6. 要求LLM给出置信度或对结果的信心/概率分数(适用于任务指令提示和系统提示)
