左值右值

  • 左值：可以取地址的对象

    • int a=5 中的 a
    • ++i （这是一个对象）

  • 右值：表达式结束后销毁的临时对象。

    • int a=5 中的 5
    • i++（返回自增前的临时值）
    • 纯右值（prvalue）：字面量，临时对象
    • 将亡值（xvalue）：通过 std::move 转换后的对象（即将被销毁，可被 “移动” 资源的对象）

  • std::move 用于完成移动构造。移动构造避免不必要的拷贝，提高性能

        class MyString {
        private:
            char* data;
        public:
            // 移动构造：窃取other的data，避免深拷贝
            MyString(MyString&& other) noexcept 
                : data(other.data) { 
                other.data = nullptr; // 原对象资源被转移，避免析构时重复释放
            }
    };
    //用法
    MyString a("hello");          // 普通构造
    MyString b = std::move(a);    // 用 std::move 把 a 转成右值引用
                                // 调用移动构造函数，“偷”a的资源

继承 & 多态

class Animal {
    public:
        string name;

        Animal(string n) : name(n) {}

        virtual void speak() {
            cout << "Animal speaks" << endl;
        }

        virtual ~Animal() {} // 需要释放具体对象的资源
};

运行时绑定（dynamic dispatch）

  • 每一个含有virtual function 的类，都会有一个虚函数表.
  • 这个类的每个对象，都会有一个额外的 field 叫做 vptr。如果被初始化为某个子类的对象，它指向那个子类的 vtable，里面放着子类实现函数的实际地址
