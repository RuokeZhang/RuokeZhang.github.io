2192. 有向无环图中一个节点的所有祖先

要找到某个节点的所有祖先，但是不需要在dfs的时候把所有本次搜索经过的节点都带上，因为，我们会遍历每个节点，作为起点。所以在搜索的时候，我们只要把这个起点加进祖先列表即可。

dfs条件：当下一个节点在本次搜索之中，没有被搜到过的时候，可以去遍历它.所以每次dfs的时候，vis[i]表示这次搜索的起点，

遍历过该节点，需要恢复它吗？

不需要.
比如0->3->6, 0->4->6。第二次到6的时候其实是不同的一条路，这个时候6被标记为没有被访问过～

当 start = 0：

走路径 0→3→6 时，第一次到达 6，满足 vis[6] != 0，于是 ans[6].append(0)，然后你回溯时如果写了 vis[6] = -1，等于擦掉“6 已被 start=0 访问过”的标记。

回到 0 再走另一条路径 0→4→6，再次检查到 vis[6] != 0（因为被你复原成了 -1），又会 ans[6].append(0) —— 同一个祖先 0 被加了两次。

1293. 网格中的最短路径

最多可以消除K个障碍物：最多可以经过K个障碍物
搜索状态(x,y,rest)表示在此处还可以经过rest个障碍物.

网格图 0-1 BFS

专门解决「边权只可能是 0 或 1」的最短路问题，它把 Dijkstra 的“按距离最小弹出 + 优先队列”思路，换成了“双端队列 deque + 常数时间插入”——一旦边权只有 0/1，就能把 O(E log V) 降到 O(E + V)。

为什么可以这样做？因为BFS队列只包含“这一层”和“下一层”的节点。而0-1网格图中，边权只有0或1，也就对应“这一层”和“下一层”，所以用双端队列就可以实现用堆的Dijkstra。

时间复杂度为O(V+E)

from collections import deque

INF = 10**18

def zero_one_bfs(n, adj, s):
    """
    n: 顶点个数 [0..n-1]
    adj[u]: 列表 [(v, w)]，其中 w ∈ {0, 1}
    s: 源点
    return: dist 数组
    """
    dist = [INF] * n
    dist[s] = 0
    dq = deque([s])

    while dq:
        u = dq.popleft()
        for v, w in adj[u]:
            nd = dist[u] + w
            if nd < dist[v]:
                dist[v] = nd
                if w == 0:
                    dq.appendleft(v)  # 同层：放队首
                else:
                    dq.append(v)      # 下一层：放队尾
    return dist

1368. 使网格图至少有一条有效路径的最小代价

欧拉回路

欧拉通路（Eulerian Path）：是一条通过图中所有边恰好一次的路径，不要求遍历所有顶点（因为某些顶点可能没有边，或者不是路径的一部分）。

欧拉回路（Eulerian Circuit）：是一条通过图中所有边恰好一次且起点终点相同的回路，也不要求必须经过所有顶点。

欧拉图：包含欧拉回路的图；

半欧拉图：包含欧拉通路但不包含欧拉回路的图。

  1. 对于无向图 G，G 是欧拉图当且仅当 G 是连通的且没有奇度顶点。
    对于无向图 G，G 是半欧拉图当且仅当 G 是连通的且 G 中恰有 0 个或 2 个奇度顶点。
  2. 对于有向图 G，G 是欧拉图当且仅当 G 的所有顶点属于同一个强连通分量且每个顶点的入度和出度相同。
  3. 对于有向图 G，G 是半欧拉图当且仅当
  • 如果将 G 中的所有有向边退化为无向边时，那么 G 的所有顶点属于同一个强连通分量；
  • 最多只有一个顶点的出度与入度差为 1；
  • 最多只有一个顶点的入度与出度差为 1；
  • 所有其他顶点的入度和出度相同

332. 重新安排行程

此图是一个半欧拉图，且固定起点为JFK。因此，图中唯一出度比入度小1的节点是终点

Hierholzer 算法的核心思路是：

  1. 从起点出发，深度优先遍历图中还没被访问的边。
  2. 一旦当前点没有未访问的边了，就将它加入最终路径中（回溯）。
  3. 回溯过程会将路径倒着加入，最后再把路径逆序得到答案。

dijkstra

✅ 图搜索问题
✅ 最优路径问题（要找最优等待时间)
✅ 非负权重（高度值非负）

当一个节点出堆的时候，就代表它的最短路一定已经找到了（虽然此时弹出的距离不一定是最短距离）

一个节点第一次出堆的时候，这个时候弹出的dx一定是最小值，且dx==dist[x]

在正权图的 Dijkstra + 懒删除实现里， 每当一个节点从堆顶弹出时，它的最短路长度 dist[x] 已经确定； 如果 dx == dist[x]，确定发生在当前弹出； 如果 dx > dist[x]，确定发生在之前那次满足相等条件的弹出。

def bellman_ford(n: int, edges: List[List[int]], src: int) -> List[float]:
    dist = [inf] * n
    dist[src] = 0

    # 最多 n-1 条边 => 做 n-1 轮松弛
    for _ in range(n - 1):
        updated = False
        prev = dist[:]          # 同样用上一轮的结果
        for u, v, w in edges:
            if prev[u] == inf:
                continue
            if dist[v] > prev[u] + w:
                dist[v] = prev[u] + w
                updated = True
        if not updated:         # 可选的小优化：无更新就提前结束
            break

    return dist

from typing import List

class Solution:
    def findTheCity(self, n: int, edges: List[List[int]], distanceThreshold: int) -> int:
        # 步骤1：初始化距离矩阵
        dis = [[float('inf')] * n for _ in range(n)]
        
        # 自己到自己距离为0
        for i in range(n):
            dis[i][i] = 0
        
        # 填入直连边的距离
        for a, b, w in edges:
            dis[a][b] = w
            dis[b][a] = w  # 无向图
        
        # 步骤2：Floyd 三层循环
        # 最外层：枚举中间节点 k
        for k in range(n):
            # 中间层：枚举起点 i
            for i in range(n):
                # 最内层：枚举终点 j
                for j in range(n):
                    # 尝试通过 k 中转，看是否更近
                    if dis[i][k] + dis[k][j] < dis[i][j]:
                        dis[i][j] = dis[i][k] + dis[k][j]
        
        # 步骤3：找答案
        min_count = n  # 最少可达城市数
        ans = -1       # 答案城市编号
        
        for i in range(n):
            # 统计从城市 i 出发，能在阈值内到达的城市数
            count = 0
            for j in range(n):
                if i != j and dis[i][j] <= distanceThreshold:
                    count += 1
            
            # 题目要求：数量相同时选编号大的
            if count <= min_count:
                min_count = count
                ans = i
        
        return ans
