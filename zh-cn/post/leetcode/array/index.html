2444. 统计定界子数组的数目

  • 假设所有元素都在minK, maxK 之间，那么一边遍历 array，一边看是否出现 minK, maxK，以及记录它们的 index。若当遍历到某个数时，minK 和 maxK 都找到了，则以此时的 i 为右端点，左端点在 [0,min(minI, maxI)]的所有subarray 都符合条件
  • 但事实上，有些元素不在[minK, maxK]之间，那么需要一个额外的 index 来记录上次越界元素出现的位置。则，minK和 maxK 都需要在 index 右边出现才行。并且左端点需要在[index+1, min(minI, maxI)]之间

287. 寻找重复数

给定一个包含 n + 1 个整数的数组 nums ，其数字都在 [1, n] 范围内（包括 1 和 n），可知至少存在一个重复的整数。

如果一个数组中没有重复的数，比如[1,3,4,2]。遍历index:从0到n-1 ，建立index到nums[index]的映射

0->1->3->2->4->null

如果有重复的数，比如[1,3,4,2,2]，因为所有元素都在[1, n] 范围内，所以必然存在一个环。为什么答案即环的起点呢？因为存在i,j，使得nums[i]=nums[j]=x，即两个节点会指向同一个节点

0->1->3->2->4->2->4

vis = [False] * n  # 标记该下标是否在某个环中被访问过

for v in a:        # 遍历所有下标（这里遍历的是 a 中的值，其实就是 0..n-1 的一个排列）
    if vis[v]: continue  # 已经在前面的环里访问过，跳过
    while not vis[v]:    # 否则，这里开始顺着 v -> a[v] -> a[a[v]] 走，直到回到已经访问过的点
        vis[v] = True
        v = a[v]
    ans -= 1  # 走完一圈，说明发现了一个完整的环

2471. 逐层排序二叉树所需的最少操作数目

比如说排序一个数组，每次操作可以两两交换，希望找到最少需要的操作数量。
array=[2,0,1,4,3] 这里[2,0,1]是一个置换环，[4,3]是一个置换环。

从第一个数开始，把这个数字当成下标去访问数组，不断循环直到回到这个数本身。

我们只需要计算每个环内需要多少次交换。对于每个环，交换次数为环的大小减一。

如果一个数组有N个数字，有M个环，则总共需要的交换次数为N-M

子数组包含的 偶数 和 奇数 数量相等。

N xor M=K, K xor N=M，保持一个记录当前xor的变量，如果想把某个数字N从窗口中移除，直接 xor N即可

所以，可以对xor作前缀和
