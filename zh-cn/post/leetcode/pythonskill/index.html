import heapq

heap = []
heapq.heappush(heap, 3)

heapq.heappush(heap, 2)
print(heap)  # 输出: [1, 3, 2]

对于单个元素：如果元素是可比较的（例如整数、浮点数等），那么堆会根据元素的大小进行排序，最小的元素位于堆顶。
对于元组元素：当元素是元组时，堆会首先比较元组的第一个元素。如果第一个元素相等，再比较第二个元素，以此类推。在你给出的代码中，压入堆的元素是 (value, key) 元组，堆会根据 value（即元素出现的频率）进行排序，value 最小的元素位于堆顶。

heapify(pq) 的作用是将任意列表转换为合法的最小堆，时间复杂度为 O (n)。

转换后： pq[0] 是最小值。
其他元素的位置满足堆性质，但不保证整体有序。

绝大多数算法题 / 数据处理：优先使用 .split()。它能帮你自动清洗掉多余的换行符、缩进和连续空格，直接拿到干净的单词或数字列表。

运算符优先级陷阱：<< 与 -

在 Python 中，减法 - 的优先级高于左移 <<。因此：

1

return 1 << rh - 1  # 错误在这里！

会被解析成 1 << (rh - 1)，即 $2^{rh - 1}$。

但满二叉树节点数量的公式是 $2^{rh} - 1$，正确写法应加括号：

1

return (1 << rh) - 1

Master Theorem

$T(N) = aT(N/b) + O(N^d)$

三种情况及结论（简化版 $f(N) = O(N^d)$）

关系主导方时间复杂度 $T(N)$经典算法代表
$\log_b a > d$叶子节点主导（底层的子问题太多了）$O(N^{\log_b a})$矩阵乘法 Strassen 算法
$\log_b a = d$每一层均匀分布（工作量平摊在每层）$O(N^d \log N)$归并排序、二分查找
$\log_b a < d$根节点主导（顶层的额外花费 $f(N)$ 太大）$O(f(N))$ 即 $O(N^d)$比较少见的非均衡划分

① 二分查找 (Binary Search)

递推式：$T(N) = T(N/2) + O(1)$

参数：$a=1, b=2, d=0$

比较：$\log_2 1 = 0$，与 $d=0$ 相等（情况 2）

结论：$O(N^0 \log N) = O(\log N)$

② 归并排序 / 树的层序分治

递推式：$T(N) = 2T(N/2) + O(N)$

参数：$a=2, b=2, d=1$

比较：$\log_2 2 = 1$，与 $d=1$ 相等（情况 2）

结论：$O(N^1 \log N) = O(N \log N)$

③ 汉诺塔 / 满二叉树遍历

递推式：$T(N) = 2T(N/2) + O(1)$

参数：$a=2, b=2, d=0$

比较：$\log_2 2 = 1 > d=0$（情况 1）

结论：$O(N^{\log_2 2}) = O(N)$
