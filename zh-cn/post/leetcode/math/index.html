def det(x1: int, y1: int, x2: int, y2: int) -> int:
    return x1 * y2 - y1 * x2

result = det(B.x - A.x, B.y - A.y,    # 向量 AB
             C.x - B.x, C.y - B.y)    # 向量 BC

结果判断：

  • result > 0：C 在 AB 的左侧（逆时针转向）
  • result < 0：C 在 AB 的右侧（顺时针转向）
  • result = 0：A, B, C 共线

下凸包 凸包上相邻的三个点必须形成"左拐"（逆时针转向），不能"右拐"或"走直线"

从左往右、从下往上遍历所有点。建立一个栈，假设已经加入A, B

如果det(AB,BC)>0，则ABC是一个合理的下凸包

如果det(AB,BC)<=0，则弹出B，加入C

def gcd(a: int, b: int) -> int:
    while b:
        a, b = b, a % b
    return abs(a)
