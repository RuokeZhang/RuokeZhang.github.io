PinClip

image encoder

  • CNN Stem：卷积天然具有 “平移不变性” 和 “局部性” 的归纳偏置，非常擅长捕捉边缘、纹理等低层次视觉特征
  • Funnel ViT：处理高层次语义；显著降低预训练的计算成本和内存使用
  • 最后 12 层不冻结，经过I2T训练

text encoder

  • SigLIP
  • descriptive text: The sparkling glitter adds a touch of glamour to any outfit…
  • keyword text: men shoes/streetwear/sneaker，更像是一个search query
  • 不是把两种text拼接在一起,因为太长影响效果
  • 全程可训

Fusion encoder

  1. 把image和text token拼接起来，得到[I1, I2, …, T1, T2, …], 维度[N, d], N=Nv + Nt
  2. 过 2 层 Transformer, 得到Z_j，维度[N, d]
  3. 然后做Attention Pooling
    • r_j = MHA(q, Z_j, Z_j), [1, d]
    • q:[1,d]
  4. L2 normalization，最后每个 pin 的 embedding 就是 r_j

Image-to-text Alignment

  • 每个 image-text pair 单独做 binary classification,每一个pair只有两个取值，match/unmatch
  • L_I2T = L_desc + L_key
  • I → image encoder → image embedding
  • T_desc → text encoder → desc text embedding
  • T_key → text encoder → keyword text embedding
  • 用sigmoid loss, BCE-with-logits
    • 正样本 loss = -log(sigmoid(score))
    • 负样本 loss = -log(1 - sigmoid(score))

Pin-to-Pin alignment

  • image tokens + descriptive text tokens经过Fusion Encoder，得到fused Pin embedding M’_j
  • 也是BCE，score = t * (u_i · v_j) - c
    • t: temperature, 属于[-1, 1]，作用是把 similarity 的差异放大或缩小
    • c: bias，决定 similarity 要高到什么程度，模型才认为这对 pair 是正样本。需要bias是因为 contrastive learning 里负样本远多于正样本
    • u_i，v_j：同一个batch中每个pin的fused embedding
  • random walk：从一个 query Pin 出发，在图上随机走，走很多次之后，看哪些 Pin 被访问得最多。
  • For each query Pin, sample N = 5 positive Pins。离线计算每个 query Pin 的 top 50 neighbor candidates，训练时sample N = 5. 最后有2.4 billion Pin pairs

MRL

L_total = L_I2T(full 256d) + L_P2P(full 256d)

  • 0.1 * L(prefix 64d)
  • 0.1 * L(prefix 128d)
  • 1.0 * L(prefix 256d)

int8 embedding quantization

  • x_q = round(x / s + z)
  • x_dq = (x_q - z) · s

x      = 原始 float 数值
s      = scale，刻度大小
z      = zero-point，零点偏移
x_q    = quantized int8 数值，真正存起来的整数
x_dq   = dequantized 数值，还原后的近似 float

比如x=0.123, s=0.01,z=0 那么x_q=12, 是一个int8. 存embedding的时候就存x_q
然后x_dq=0.12，和原来的会有误差

PinPoint

Composed Image Retrieval (CIR)

用户给一张参考图，再加一句修改指令，让系统找出符合“图像 + 指令”的目标图

Dataset

  • 从互联网爬取25000 张公开候选查询图，覆盖 23 个大类（服饰、美妆、家居软装等）
  • 对每一张原图，生成 3~5 条自然语言修改提示词，指令分成 5 种类型：Explore（拓展场景）、Swap（替换物品）、Negation（移除某物）、Context Fit（适配场景）、Complement（补充物件）。
  • 对每个提示词，人工filter一下，然后再让大模型改写3-5条提示词。这3-5条提示次对应完全一样的正负样本
  • 针对单条检索指令输出两类文本：
    • 有效正样本描述：符合需求的物品（例：藏青色翻领纽扣衬衫）
    • 易混淆假正例描述：看着相近但不符合（例：红色衬衫、蓝色长裤）
  • 每一条描述最多爬 50 张图片，单条查询最终汇总出 100 张候选图片
  • LLM 给每张候选图划分 5 类标签：
    • 高度相关/部分相关/不相关/略微无关/假正例(False Positive)
  • 人工复核，平均每条查询：9.1 张正样本 + 32.8 张精准负样本；
    • 所有正负样本 + 海量无关图片合并，最终 PinPoint 完整检索图库：109601 张图片

Evaluation

metrics

  • ΔmAP@10：衡量模型会不会误召回迷惑性假图
    • ΔmAP@10=mAP@10 no_hn−mAP@10 all, 越低越好
  • Linguistic Sensitivity 语言敏感度：衡量模型对用户不同说话方式的鲁棒性 ​

Methods

  • Clip Baselines
    • 选用没有经过 CIR（组合图像检索）专项微调的通用开源图文大模型：Meta CLIP2、Apple DFN-CLIP
    • image-only：只使用参考图片的特征检索，完全丢掉用户的文字修改指令；
    • text-only：丢弃参考原图，只拿修改指令的文本去检索；
    • early fusion：图片 Embedding、文本 Embedding 分别归一化后，提前融合向量，再用融合后的特征检索；
    • SLERP interpolation：球面插值算法，在向量空间插值混合图文特征，是经典的特征融合方案。
  • CIR Specific Methods
    • MMRet
      • 训练：(query image, instruction text, target image)
  • Proxy-based Methods
    • 先根据原图 + 指令，生成一个代表目标图的代理 (Proxy)，再编码这个 Proxy、用 Proxy 去检索图
    1. 用 GPT-5，输入参考原图 + 用户修改指令，让大模型生成目标成品图的详细文字描述（这段文字就是 Text Proxy）；
    2. 把生成的描述送入 Meta CLIP2 文本编码器，只靠文本特征做纯文本检索；
    3. 为了规避描述长短带来的波动，对同一个查询生成短 / 中 / 长 3 种篇幅的描述，提供两种结果融合方案：
    • pre-merge（前融合）：先把 3 段描述的 CLIP 文本特征做平均融合，得到 1 个向量，再去检索；
    • post-merge（后融合）：3 段描述各自单独检索得到 3 份结果榜单，最后根据相似度分数合并三份列表。

Training-Free Point-wise Reranking

  • 无训练、即插即用的逐候选重排序算法，不改动前面任何基础检索模型，在粗召回结果上二次精筛，专门干掉假正干扰图、提升 Top10 精度
    1. 一阶粗召回：CLIP/CIR/Text Proxy 任意一种方法，先从 10w 图库捞出一批候选图片；
    2. 二阶重排：用MLLM 对粗召回结果逐个打分、重新排序
  • 对每一张候选图，固定 Prompt 格式送入 Qwen-VL：Given the query image and the instruction: {T}, is the candidate image relevant? Answer with ‘yes’ or ‘no’ only.
  • 得到每一张候选图的原始打分 logit, 然后做 sigmoid, 再排序
