Airline Ticketing Design

Airlines offer different ticket classes such as Economy, Business, and FirstClass.

Each ticket has the following attributes:

  • airline_name
  • class_name
  • mileage

Example input:

1
2
3
4

tickets = [
    ["American", "Economy", 120.0],
    ["RyanAir", "Business", 100.0],
]

The operating cost depends on the ticket class. The initialization data is given as follows:

1
2
3
4
5

operating_cost_init_data = [
    ["Economy", 50.0, 0.05],
    ["Business", 100.0, 0.15],
    ["FirstClass", 150.0, 0.25],
]

The operating cost for a ticket is computed as:

1

operating_cost = base_operating_cost + per_mile_cost * mileage

For example:

  • Economy: 50.0 + 0.05 * mileage
  • Business: 100.0 + 0.15 * mileage
  • FirstClass: 150.0 + 0.25 * mileage

Different airlines use different pricing rules to determine the final ticket price.

Airline pricing rules

American

American charges:

1

ticket_price = operating_cost + mileage

RyanAir

RyanAir charges the maximum of:

1
2

2 * operating_cost
1.5 * mileage

So its final formula is:

1

ticket_price = max(2 * operating_cost, 1.5 * mileage)

Task

Design a system in Python that computes the final ticket price for each ticket.

Your design should make it easy to:

  • add new airlines
  • add new pricing rules
  • extend the system without large changes to existing code

Note that pricing rules may become more complicated in the future. For example, an airline may use different pricing tables for different ticket classes.
