General

  • X^m = (s_global^m, K object slots)
  • each object slot = semantic embedding s_i^m + spatial attributes r_i^m + confidence c_i^m

Encoder

Audio Semantic Encoder

Input:

  • two-channel binaural waveform: [B, 2, T]

Steps:

  1. Average L/R binaural waveform into mono.
  2. Resample to 16 kHz.
  3. Use frozen M2D-CLAP audio encoder to extract semantic audio patch tokens.

Output before alignment:

  • M2D-CLAP semantic audio tokens: [B, 310, 768]
  1. Use pretrained residual MLP alignment module: [B, 310, 768] → [B, 310, 1152]

Output:

  • F_A^sem / H_A^sem: [B, 310, 1152]

Notation:

  • F_A^sem means audio semantic context tokens.
  • These tokens are used as memory/KV for the audio semantic decoder.

Audio Spatial Encoder

这是唯一一个 encoder 层中可训练的模块

  • 对10s audio的L/R做resample, 采样率是16kHZ, 所以single sample: [2, 160000]
  • 对L/R的waveform分别作STFT, 得到L/R的magnitude和phase
    • n_fft = 1024，hop_size = 512，代表对每一段取1024个采样点，步长为512.
    • freq_bins = n_fft / 2 + 1，代表spectrogram的纵轴一共有513个bin
    • T_stft = floor(160000 / 512) + 1 = 313, 代表横轴一共被分成313个时间块
    • 这里得到[B, 4, 513, 313]. 4代表L/R的magnitude/phase
  • CNN
    • 一共用三个CNN blocks：Conv(3×3, 64ch) → ReLU → BN → MaxPool(freq axis) × 3 层
    • 假设maxPool的stride是2， 那么经过三层CNN后，得到[B, 64, 64, 313]
  • 对freq做average，得到[B, 64, 313]. 也就是每个时间块的freq做average，每个时间块得到一个64维的特征
  • linear projection: [B, 313, 1152]
  • interpolate length 313 → 310, 得到[B, 310, 1152]，也就是F_A^spa
  • F_A = F_A^sem + F_A^spa

Visual Encoder

Input:

  • image I

Steps:

  1. Use frozen SigLIP2 visual tower.
  2. Output visual patch/context tokens.

Output:

  • F_V / H_V: [B, 256, 1152]

Notation:

  • F_V or H_V means visual context tokens / visual patch tokens.
  • Do NOT call this sem_V, because sem_V can be confused with semantic object slots.
  • These patch tokens preserve image layout, so they contain both semantic and spatial evidence.

Text Encoder

Input:

  • global scene description
  • object-level clauses with spatial labels

Text encoder:

  • frozen SigLIP2 text encoder

Global scene text

Scene description → tokenizer → frozen SigLIP2 text encoder → global text embedding

Output:

  • s_global^T: [B, 1152]

Used for:

  • global contrastive alignment.

Object clauses

Each object clause is encoded separately.

Example object clause: “Truck engine sound | slight right, level, close”

Text encoder only encodes the semantic text part / clause representation. The spatial labels are used directly as GT labels.

Output:

  • object semantic embeddings: s_j^*: [B, M_max, 1152]

where:

  • M is the number of GT object clauses in this sample.
  • M is variable.
  • M is NOT equal to K.
  • K = 50 is the fixed number of predicted object slots.

Decoder

Semantic Decoder

  • 对Audio和Visual分别做cross attention
    • Audio: 使用 F_A^sem / H_A^sem, [310, 1152]
    • Visual: 使用 F_V / H_V, [256, 1152]
    • Learnable Queries: Q_raw = [q_global, q_1, q_2, …, q_K]=[51, 1152], K=50
  • Cross Attention (Audio for Example)
    • Q
      • Q_raw = learnable query embeddings, [51, 1152]
      • W_Q = learnable projection matrix, [1152, d_k]
      • Q = Q_raw @ W_Q, [51, d_k]
    • K/V
      • K_raw = V_raw = F_A^sem / H_A^sem, [310, 1152]
      • K: [310, d_k]
      • V: [310, d_k]
    • Q@K_T: [51, 310], 每个 query 对 310 个 audio patch 的相关性分数
    • softmax, 对于每一个slot query, 看哪些audio patch和自身的相关性更高，所有相关性之和为1.
    • @V, 得到[51, d_k],代表 51 个 query 各自从这段10s音频里“提取/汇总”出来的 51 个结果向量。
    • multi-head拼接，最后得到[51, 1152]。其中后50个叫做 h_A: audio object hidden states
  • Heads
    • semantic slot head
      • learnable。audio和visual的 h_A / h_V 都要经过这个，得到 s_A = g_sem_A(h_A)，形状仍然是[50, 1152]
    • confidence head
      • learnable, h_A: [B, 50, 1152]
      • → confidence head,得到logits: [B, 50, 1]
      • → sigmoid，得到 c_A: [B, 50]

Spatial Decoder

  • Q: object semantic slots
    • s_A: [B, 50, 1152] # audio object semantic slots
    • s_V: [B, 50, 1152] # visual object semantic slots
  • K/V:
    • audio: F_A = F_A^sem + F_A^spa, [B, 310, 1152]
    • visual: F_V / H_V, [B, 256, 1152]
  • 做一层cross attention，得到
    • z_A = D_spa^A(s_A; F_A)
    • z_V = D_spa^V(s_V; F_V)
  • 接三个 projection heads
    • u_m^θ = g_θ^m(z_m) # azimuth embedding
    • u_m^φ = g_φ^m(z_m) # elevation embedding
    • u_m^d = g_d^m(z_m) # distance embedding
  • audio和visual共用一个classifier
    • azimuth_logits: [B, 50, N_azimuth_bins]
    • elevation_logits: [B, 50, N_elevation_bins]
    • distance_logits: [B, 50, N_distance_bins]
    • 每个 scene 预测 50 个 candidate object slots，每个 slot 都有一套 logits
  • 对于每个scene, 最后输出(以audio为例)

    • s_A: [50, 1152] # 50 个 audio semantic slots

    • c_A: [50] # 50 个 confidence scores

    • azimuth_logits_A: [50, N_azimuth_bins]

    • elevation_logits_A: [50, N_elevation_bins]

    • distance_logits_A: [50, N_distance_bins]

Training

Bipartite Matching

  • 50个slots和GT分别算matching score
  • matching score定义：a_ij^m = [(1 - λ) cos(s_i^m, s_j*) + λ ρ_ij^m] (α + β c_i^m)
    • s_i^m: audio/visual predicted semantic slot
    • c_i^m: audio/visual confidence
    • s_j*: j-th GT object clause text embedding
    • ρ_ij^m
      • slot i 的空间预测 和 GT object j 的空间标签 有多匹配
      • ρ_ij^A = [p_i^{A,θ}(GT azimuth) + p_i^{A,φ}(GT elevation) + p_i^{A,d}(GT distance)] / 3
  • 对每个 modality m ∈ {A, V}，单独做一次 Hungarian matching。

Object Grounding Loss

  • semantic loss
    • L_sem^m = Σ_(i,j)∈Ω^m [ 1 - cos(s_i^m, s_j*) ]
    • (i,j)∈Ω^m表示一种modality的slot i <=> GT j配对
    • s_i^m表示semantic embedding
    • s_j* 表示GT 的semantic annotation text embedding
  • Spatial loss
    • L_spa^m = Σ_(i,j)∈Ω^m [
      CE_θ(logits_i^{m,θ}, y_j^θ) +
      CE_φ(logits_i^{m,φ}, y_j^φ) +
      CE_d(logits_i^{m,d}, y_j^d)]
    • 用Gaussian-smoothed cross-entropy。
      • 比如 GT 是 slight right，target 可能变成：target = [0.00, 0.01, 0.08, 0.20, 0.42, 0.20, 0.08]
      • Loss = -Σ q_k log(p_k).
      • q_k表示这个GT target, p_k表示模型输出的softmax后的logits
  • confidence loss
    • L_conf^m = Σ_i BCE(c_i^m, y_i^conf)
    • y_i^conf = 1, if slot i is matched
    • y_i^conf = 0, otherwise
    • 因为每个slot都有一个confidence，但不是每个slot都能match上GT。对于能match上的slot, 我们希望它的confidence接近1

Global Contrastive Loss

  • 训练global scene embedding
    • s_global^A # audio global embedding
    • s_global^V # visual global embedding
    • s_global^T # text global embedding
  • L_global = L_AV + L_AT + L_VT，分别对三种配对计算symmetric InfoNCE
    • L_AV = (L_A2V + L_V2A) / 2

Object-centric Contrastive Loss

  • match同一个物体的audio和visual
  • 对每个 matched object，都可以算一个 object-level InfoNCE

SceneBind Matching

比如一个A->V任务，拿一个Audio去retrive image（整个scene)

  • S(X^A, X^V) = norm(S_global) + λ_match * norm(S_obj)

  • global score: S_global = cos(s_q_global^A, s_c_global^V), q代表query，c代表candidate

  • object score:

    • 对 query audio 里的每个 active slot， 去 candidate visual 的 slots 里找一个 best match， 然后把这些 best-match 分数做加权平均。

    • best match就是对于某个audio slot来说，和所有的candidate visual slot算score，里面最高的score

    • object_pair_score(i, j) = semantic similarity × spatial similarity × confidence weight

    • score_ij^{A,V} = w_ij · cos(s_i^A, s_j^V) · ρ_ij^{A,V}

    • s_i^A = audio 的第 i 个 object semantic slot

    • s_j^V = visual 的第 j 个 object semantic slot

    • c_i^A = audio slot i 的 confidence

    • c_j^V = visual slot j 的 confidence

    • ρ_ij^{A,V} = [2⟨π_i^{A,θ}, π_j^{V,θ}⟩+ ⟨π_i^{A,φ}, π_j^{V,φ}⟩+ ⟨π_i^{A,d}, π_j^{V,d}⟩ ] / 4

      • π_i^{A,θ}, π_i^{A,φ}, π_i^{A,d} are softmax-normalized spatial distributions from audio slot i
      • inner product measures whether two slots predict similar spatial bins
      • azimuth is weighted by 2 because horizontal direction is the main cue for binaural audio

    • w_ij = sqrt(c_i^A · c_j^V)

Spatial Retrieval

Speech

waveform

  • 一串数字，声音随时间变化的振幅值，采样率16 kHz代表每秒采集 16000 个声音数据点
  • 形状：x(t)=A⋅sin(ωt+φ)。φ代表phase也就是相位; A代表magnitude
  • 横轴：time
  • 竖轴：振幅 Amplitude
  • 波形疏密决定音调
    • 密 = 高频 = 高音
    • 疏 = 低频 = 低音

Spectrum

  • 横轴 X：频率 Frequency（Hz）
    • 从左到右：低音 → 中音 → 高音
  • 纵轴 Y：能量 / 音量
    • 越高 = 这个音调越响

spectrogram

  • 横轴 X = Time 时间（声音从头到尾）
  • 纵轴 Y = Frequency 频率（下低上高，低音→高音）
  • 颜色 / 亮度 = 音量
    • 越亮 / 越暖：声音越大
    • 越暗 / 越冷：声音越小、静音

STFT

  • 把时域波形数组切成一小段一小段 帧 (frame)
  • 每帧加窗函数（常用汉宁窗 Hann），避免断层杂音
  • 对每一帧单独做傅里叶变换
  • 按时间顺序拼接所有帧频谱 → 直接得到语谱图
