Lecture 6

Word Embeddings & X2Vec

Word2Vec

  • Skip-Gram， semi-supervised
  • 生成训练数据：通过移动窗口扫描句子，生成 (输入词, 目标词) 对
  • 架构：input(one-hot), 1 hidden layer, softmax classifier

Product2Vec (X2Vec)

  • View Similarity：学习 Substitutability（可替代性/严格相似）
  • Purchase Similarity：学习 Complementarity（互补性/搭配关系）

BERT

  • bert base: 12 layers of encoder
  • [CLS]：放在句首，用于整个句子的分类表示。
  • [SEP]：放在句尾或两句之间，作为分隔符。
  1. normalization： all lower case
  2. WordPiece Tokenization
  3. add special tokens: [CLS]/[SEP]
  4. Token IDs(BERT vocab)
  5. each token got 3 embeddings，sum them up
    • token embedding(get from a huge matrix, size of [Vocab_Size, 768])
    • position embedding(get from a matrix, size of [Max_Len, 768])
    • segment embedding
  6. got a matrix[token_size*768]
  7. pass the matrix through a 12 Encoder Layers. After that, [CLS] would gather information from the entire sentence

outputs

  • last_hidden_state: 一组tensor，每个tensor是每一个单词的768维向量
  • pooler_output: 一组tensor，第i个tensor表示整个第i句话的综合表示 (768维)

  • context_rep == “cls”: 取[CLS]的向量作为这句话的代表
  • context_rep == “mean_pool”: 得到所有单词embedding的平均值

# Hyperparameters
CONTEXT_REP = 'cls'
CLF_TYPE = 'non-linear'
LEARNING_RATE = 0.008
BATCH_SIZE = 32


# 1) Load BERT once and freeze it
device = 'cuda:0'
bert = BertModel.from_pretrained("bert-base-uncased").to(device)
for p in bert.parameters():
    p.requires_grad_(False)

# 2) Precompute embeddings ONCE
X_train, y_train = compute_embeddings(bert, train_loader, device, context_rep=CONTEXT_REP)
X_val, y_val     = compute_embeddings(bert, val_loader, device, context_rep=CONTEXT_REP)
X_test, y_test   = compute_embeddings(bert, test_loader, device, context_rep=CONTEXT_REP)

# output: [batch_size, 768]

# 3) Build embedding loaders (much faster)
train_emb_loader = DataLoader(EmbeddingDataset(X_train, y_train), batch_size=BATCH_SIZE, shuffle=True)
val_emb_loader   = DataLoader(EmbeddingDataset(X_val, y_val), batch_size=BATCH_SIZE, shuffle=False)
test_emb_loader  = DataLoader(EmbeddingDataset(X_test, y_test), batch_size=BATCH_SIZE, shuffle=False)

# 4) Train a small head for many epochs cheaply
hidden_size = X_train.shape[1] # 768
head = make_head(hidden_size, num_labels=5, classifier_type=CLF_TYPE).to(device) # make a classifer (linear/nn)
opt = torch.optim.AdamW(head.parameters(), lr=LEARNING_RATE)

best_head = train_head(head, train_emb_loader, val_emb_loader, opt, device, num_epochs=10, eval_every_epochs=1)

training process

Forward Pass

假设句子为 machine think, length=2

  1. a token get its defualt embedding from the initial huge matrix

    • 分别与矩阵Wq,Wk, Wv相乘，得到Q,K,V.
    • 每个权重矩阵的size都是[64,768]. 因为bert=12 heads, 768/12=64.
    • Q,K,V size=[2, 64]

  3. calculate Attention Scores

    • 拿当前 Token 的 $Q$ 去和所有 Token 的 $K$ 做点积

  4. row-wise softmax. 现在每一行（一个token）的总和为1

  5. 把这个得到的相似度矩阵和V相乘，得到Z，然后把12个Z拼接到一起
