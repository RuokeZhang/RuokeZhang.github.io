网络

发表于： 2025-03-29 分类于： NetWork

TCP 重传

  1. 超时重传：设置一个计时器，时间应略长于RTT。如果超时了还没有收到ACK，则立即重传
  2. 快速重传：当连续收到三个相同的 ACK 时，立即重传
  3. SACK（选择性确认）：接收方可以告诉发送方接收到了哪几个消息，还缺哪个消息
  4. DSACK（重复确认）：接收方收到两个2，就会用DSACK告诉发送方，它有两个 2，别重传了。只是因为网络延迟问题。
